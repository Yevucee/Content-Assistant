# Brand knowledge — copy/paste examples

These files are **not** read by the harness (they use a `.example` suffix or live under `docs/`).

When you are ready to enable knowledge for a brand slug:

1. Copy into **`brands/<slug>/`**.
2. Rename by removing `.example` where applicable:
   - `partners.yaml.example` → `partners.yaml`
   - `content_notes.md.example` → `content_notes.md`
   - `template.yaml.example` → `template.yaml`
3. Replace placeholder copy with your real content (or delete sections you do not need).
4. Add **`library/`** under the slug and drop in `.md` / `.txt` files as needed.

See **`docs/brand_knowledge.md`** for the full contract and limits.
